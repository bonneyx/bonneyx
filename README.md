### Hi, I'm @nullvtx

Systems programmer & independent security researcher focusing on hardware-assisted virtualization, dynamic binary instrumentation, and control-flow de-obfuscation.

#### Research & Development Focus
- **Hardware Virtualization & VMI:** Intel VT-x / EPT & AMD-V / NPT hypervisor introspection, page-level execution monitoring, and isolated sandbox instrumentation.
- **Binary De-obfuscation:** Static analysis of virtualized bytecode handlers, Mixed Boolean-Arithmetic (MBA) expression canonicalization, and IR lifting.
- **Debugger Architecture:** Non-intrusive hardware breakpoint (`DR0`–`DR7`) tracing, Vectored Exception Handling (VEH), and crash triage tooling.
